Step 1: The Broken Lab & Observable Symptom

In a multi-subnet corporate branch topology, external clients report that they cannot connect to the DMZ Web Server (192.168.1.100:80). However, standard ICMP ping reaches the DMZ successfully.

Topology Architecture:
  • Router-1 Gi0/1 (WAN Gateway: 203.0.113.2/30)
  • Router-1 Gi0/0 (DMZ Subnet: 192.168.1.0/24)
  • DMZ Web Server IP: 192.168.1.100
  • Inbound ACL 101 applied on Gi0/1
Symptom Output:
External-Client> ping 192.168.1.100 Reply from 192.168.1.100: bytes=32 time=14ms TTL=127 External-Client> curl http://192.168.1.100 curl: (7) Failed to connect to 192.168.1.100 port 80: Connection timed out

Step 2: NetSage AI Diagnostic & Rule Inspection

NetSage extracts evidence from show access-lists 101 and correlates it with the HTTP port 80 timeout symptom.

Raw AI Diagnostic Proposal:

"Extended ACL 101 contains a deny rule on line 20 blocking TCP 80 traffic to 192.168.1.100."

⚠️ Proposed Raw AI Fix:
Router-1(config)# no access-list 101 Router-1(config)# access-list 101 permit ip any any

Step 3: Human Network Engineer Safety Catch

The human network engineer reviews the AI's proposal. Deleting the entire ACL 101 on a border router would remove firewall protection for the entire DMZ!

Human Review Decision: EDITED (Surgical Sequence Fix)

Instead of deleting ACL 101, the engineer modifies only sequence line 20 in named extended ACL mode.

Router-1(config)# ip access-list extended 101 Router-1(config-ext-nacl)# no 20 Router-1(config-ext-nacl)# 20 permit tcp any host 192.168.1.100 eq 80 Router-1(config-ext-nacl)# end

Step 4: Executing Remediated Cisco IOS Commands

Remediation commands are applied to Router-1 CLI.

Router-1# configure terminal Enter configuration commands, one per line. End with CNTL/Z. Router-1(config)# ip access-list extended 101 Router-1(config-ext-nacl)# no 20 Router-1(config-ext-nacl)# 20 permit tcp any host 192.168.1.100 eq 80 Router-1(config-ext-nacl)# end Router-1# write memory [OK] - Configuration Committed

Step 5: Post-Fix Verification & Service Recovery

Verification commands confirm that HTTP requests now successfully reach the DMZ Web Server with 0% packet loss.

Verification Output:
External-Client> curl http://192.168.1.100 HTTP/1.1 200 OK Content-Type: text/html Content-Length: 42 <html><h1>Welcome to Cisco DMZ</h1></html>
Updated ACL Matches:
Router-1# show access-lists 101 Extended IP access list 101 10 permit icmp any any (45 matches) 20 permit tcp any host 192.168.1.100 eq www (32 matches) 30 permit ip any any
